## Form Steps

| Step | Name | Fields |
|------|------|--------|
| 1 | Trainee Info | Search existing or fill new (name, DOB, sex, contact, address, civil status, education, employment) |
| 2 | Batch Selection | Pick open batch (filtered by program, shows remaining slots) |
| 3 | Document Checklist | Check off submitted requirements |
| 4 | Uniform & ID | Uniform size, OR number (auto-generated, display only) |
| 5 | Review & Submit | Summary before final submission |

## Endpoints

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/registrar/enrollments` | List all enrollments (filter by batch, status, date) |
| GET | `/registrar/enrollments/:id` | Enrollment detail |
| POST | `/registrar/enrollments` | Submit new enrollment |
| PATCH | `/registrar/enrollments/:id` | Update enrollment |
| PATCH | `/registrar/enrollments/:id/status` | Update enrollment status |
| GET | `/registrar/trainees/search?q=` | Search existing trainees |

## Test Cases

### TC-01: Multi-step form navigation
- **AC:** #1
- **Priority:** Critical
- **Precondition:** Logged in as registrar
- **Steps:**
  1. Navigate to enrollment form
  2. Fill Step 1 (Trainee Info), click Next
  3. Click Back to Step 1 → verify data retained
  4. Navigate forward through all 5 steps
- **Expected:** Data persisted across forward/backward navigation; no data loss

### TC-02: Trainee search finds existing record
- **AC:** #2
- **Priority:** Critical
- **Precondition:** Trainee "Mary Lozada" exists in database
- **Steps:**
  1. In Step 1, search for "Mary Lozada"
  2. Select the existing trainee
- **Expected:** Form pre-fills with existing trainee data

### TC-03: Create new trainee when no match
- **AC:** #2
- **Priority:** High
- **Precondition:** No trainee named "Juan Santos" exists
- **Steps:**
  1. In Step 1, search for "Juan Santos"
  2. Click "Create New"
  3. Fill in all trainee fields
- **Expected:** Form switches to blank fields for new trainee entry

### TC-04: Batch dropdown filters by availability
- **AC:** #3
- **Priority:** Critical
- **Precondition:** Batches exist: 1 full (30/30), 1 available (10/30), 1 closed
- **Steps:**
  1. In Step 2, open the batch dropdown
- **Expected:** Only batches with available slots and upcoming/ongoing status shown; full and closed batches excluded

### TC-05: OR number auto-generated in review
- **AC:** #4
- **Priority:** High
- **Precondition:** Steps 1–4 completed
- **Steps:**

  2. Inspect the OR number field

### TC-06: Enrollment saved as atomic transaction
- **AC:** #5

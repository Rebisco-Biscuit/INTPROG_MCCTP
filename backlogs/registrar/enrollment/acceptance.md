## Acceptance Criteria

### Enrollment Wizard

| # | Criteria | Status | Notes |
|---|---------|--------|-------|
| 1 | Multi-step form navigates forward and backward without losing data | PASS | EnrollmentFormWizard with 5 steps |
| 2 | Trainee search returns matching records; "create new" pre-fills form if no match | PASS | TraineeSearchOrCreate component |
| 3 | Batch dropdown only shows batches with available slots and upcoming/ongoing status | PASS | Filtered by program and slot availability |
| 4 | OR number is generated by service and displayed in Review step | PASS | Auto-generated, shown before submission |
| 5 | Enrollment saved as single transaction (trainee upsert + enrollment + requirements) | PASS | Atomic transaction |
| 6 | Duplicate enrollment (same trainee in same batch) rejected with clear error | PASS | Unique constraint enforced |

## Form Steps

| Step | Name | Fields |
|------|------|--------|
| 1 | Trainee Info | Search existing or fill new (name, DOB, sex, contact, address, civil status, education, employment) |
| 2 | Batch Selection | Pick open batch (filtered by program, shows remaining slots) |
| 3 | Document Checklist | Check off submitted requirements |
| 4 | Uniform & ID | Uniform size, OR number (auto-generated, display only) |
| 5 | Review & Submit | Summary before final submission |

## Endpoints

| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/registrar/enrollments` | List all enrollments (filter by batch, status, date) |
| GET | `/registrar/enrollments/:id` | Enrollment detail |
| POST | `/registrar/enrollments` | Submit new enrollment |
| PATCH | `/registrar/enrollments/:id` | Update enrollment |
| PATCH | `/registrar/enrollments/:id/status` | Update enrollment status |
| GET | `/registrar/trainees/search?q=` | Search existing trainees |

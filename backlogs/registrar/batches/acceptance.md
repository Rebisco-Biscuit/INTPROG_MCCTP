## Acceptance Criteria

### CRUD & Display

| # | Criteria | Status | Notes |
|---|---------|--------|-------|
| 1 | Registrar can view all batches in a table with program/status filters | PASS | BatchTable with filters |

| 3 | Registrar can create a batch — program and trainer dropdowns pull live data | PASS | Live API data, no hardcoded values |

| # | Criteria | Status | Notes |
|---|---------|--------|-------|

## Test Cases

### TC-01: View batches with filters
- **AC:** #1
- **Priority:** Critical
- **Precondition:** Logged in as registrar; batches exist for multiple programs
- **Steps:**
  1. Navigate to `/registrar/batches`
  2. Filter by program
  3. Filter by status
- **Expected:** Table shows matching batches; filters combine correctly

### TC-02: Batch code auto-generated
- **AC:** #2
- **Priority:** High
- **Precondition:** Logged in as registrar
- **Steps:**
  1. Create a new batch (leave batch code blank)
  2. Inspect the created batch
- **Expected:** Batch code auto-generated by DB trigger; displayed as read-only

### TC-03: Create batch with live dropdowns
- **AC:** #3
- **Priority:** Critical
- **Precondition:** Programs and trainers exist in database
- **Steps:**
  1. Click "Create Batch"
  2. Verify program and trainer dropdowns contain live data
  3. Fill in all fields and submit
- **Expected:** Batch created; dropdowns pull from API (no hardcoded values)

### TC-04: Slot availability counter
- **AC:** #4
- **Priority:** High
- **Precondition:** Batch exists with max_slots = 30, 10 enrolled
- **Steps:**
  1. View the batch in the table
- **Expected:** Shows "10/30" or "20 remaining" slot count

### TC-05: Forward-only status transitions
- **AC:** #5
- **Priority:** Critical
- **Precondition:** Batch with status "Upcoming"
- **Steps:**
  1. Change status to "Ongoing" → should succeed
  2. Attempt to change back to "Upcoming"
- **Expected:** Forward transition allowed; backward transition blocked

### TC-06: Editing locked fields on ongoing batch
- **AC:** #6
- **Priority:** High
- **Precondition:** Batch with status "Ongoing"
- **Steps:**
  1. Click Edit on the ongoing batch
  2. Attempt to change program, start date, trainer
- **Expected:** Critical fields locked/disabled; only non-critical fields editable
